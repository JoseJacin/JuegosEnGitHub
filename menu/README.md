# Menú principal

Este directorio contendrá la portada y el catálogo de juegos. Cada entrada enlazará a la página de su juego dentro de `../juegos/<id-del-juego>/`.

La página debe ser estática, accesible con teclado y adaptable a móvil. Las rutas deberán funcionar bajo el prefijo del repositorio de GitHub Pages. Estado: pendiente de implementación.
