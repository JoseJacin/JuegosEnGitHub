# Menú principal

Este directorio contendrá la portada y el catálogo de juegos. Cada entrada enlazará a la página de su juego dentro de `../juegos/<id-del-juego>/`.

La página es estática, accesible con teclado y adaptable a móvil. Sus rutas relativas funcionan bajo el prefijo del repositorio de GitHub Pages. Estado: catálogo inicial implementado en `index.html`.
